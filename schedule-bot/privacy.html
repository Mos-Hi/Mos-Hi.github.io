schedule-bot privacy policy

Last updated: 16 November 2026

Who uses it

schedule-bot is a personal tool used only by its owner. It does not accept sign-ins from anyone else.

What it reads

With the owner's permission, it reads events from Google calendars the owner owns, using the read-only scope calendar.events.owned.readonly. For each event it requests only the start and end time, title, colour, status and event type. It never requests descriptions, locations or attendees.

What it does with that data

  • It formats the events into a private Telegram message sent only to the owner's own chat.
  • It does not store calendar data. Data is held in memory only while a message is built, then discarded.
  • It does not log event titles or other event content. Logs contain only counts and errors.
  • It does not share, sell or transfer Google user data to anyone, and does not use it for advertising or to train AI models.
  • It never writes to, changes or deletes calendar data.

Google API Services User Data Policy

schedule-bot's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/connections.
